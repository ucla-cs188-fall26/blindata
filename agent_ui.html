Blindata: Interactive Evidence Explorer

Check an accessible chart description using the existing Blindata constraint checker, then investigate the findings with source data. This prototype uses an LLM with read-only data tools when the server is configured with an API key. Otherwise it uses offline rule-based commands.

Privacy: The checker runs locally. In LLM mode, user questions and selected chart descriptions or source values returned by the tools are sent to the configured OpenAI API. Do not enter confidential data for classroom demonstrations.
